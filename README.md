# Attendance Predictor

A beginner-friendly Python project for college students.

## Features
- Calculates current attendance percentage.
- Predicts how many classes you can miss.
- Calculates classes needed to reach the required percentage.
- Predicts attendance after the next class.

## Technologies Used
- Python
- Math module

## How to Run
1. Install Python.
2. Download attendance_predictor.py.
3. Run the following command:

python attendance_predictor.py
