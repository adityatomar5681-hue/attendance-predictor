Student Attendance Management System

A beginner-friendly Python project that calculates student attendance, predicts future attendance, and saves student records in a CSV file.

Features

- Calculate current attendance percentage.
- Check whether attendance meets the required percentage.
- Calculate how many future classes can be missed.
- Calculate how many consecutive classes are needed to reach the target.
- Predict attendance after attending the next class.
- Save student attendance records automatically in a CSV file.
- View previously saved student records.
- Simple menu-driven interface.

Technologies Used

- Python 3
- CSV module
- OS module
- Math module

Project Files

- "attendance_predictor.py" – Original attendance calculator.
- "attendance_predictor_v2.py" – Updated Student Attendance Management System.
- "attendance_records.csv" – Stores student records automatically when the program runs.

How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run this command:

python attendance_predictor_v2.py

How It Works

1. Enter the student's name.
2. Enter total classes conducted.
3. Enter classes attended.
4. Enter the required attendance percentage.
5. The program calculates attendance and saves the record.
6. Select the view-records option to see saved records.
